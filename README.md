# Ақша Трекер

Демо личного трекера трат по всем банковским картам, сделанное для себя. Одна HTML-страница без сервера и без сборки.

**Открыть:** после включения GitHub Pages приложение доступно по ссылке `https://<аккаунт>.github.io/<репозиторий>/`.

## Что умеет

- **Карты.** Kaspi, Halyk, Freedom, Jusan, BCC и другие банки, листаются свайпом. Баланс по каждой карте считается по операциям.
- **Операции:**
  - из Apple Pay через «Команды» iPhone;
  - вручную, отдельно расход и доход;
  - из текста пуша банка, вместе с балансом из «Доступно …»;
  - из выписки PDF или CSV, повторы отсекаются.
- **Лента по дням** с периодом «Этот месяц / Сегодня / Период», фильтром по категории и поиском.
- **Аналитика:**
  - доли категорий;
  - траты по дням;
  - траты нарастающим итогом в сравнении с прошлым месяцем;
  - регулярные платежи;
  - топ магазинов.
- **Лимиты и уведомления:** лимиты по категориям, предупреждения о темпе трат, крупных тратах, скорых регулярных платежах.
- **Кредиты и долги:** кредиты, рассрочки и долги с напоминанием о платеже.
- **Семейный бюджет** с общим зашифрованным пространством. Работает только при запуске внутри Claude.
- **ИИ-разбор месяца и вопросы о тратах.** Работают только при запуске внутри Claude.
- **Языки:** русский и казахский.

## Apple Pay автоматически

Делается через автоматизацию «Транзакция» в приложении «Команды» на iPhone. Подробная инструкция есть в самом приложении: «Профиль» → «Apple Pay автоматически».

- **Способ 1, сразу после оплаты.** Команда открывает `https://daulet-tuzelbek.github.io/aksha-tracker/#pay=<текст покупки>`. Пароль не нужен: страница шифрует покупку открытым ключом аккаунта и кладёт её в ящик в браузере. Расшифровать ящик можно только закрытым ключом, который хранится внутри зашифрованного хранилища, поэтому покупка попадает в ленту при следующем входе. Один раз нужно войти на этом iPhone заранее.
- **Какая карта.** Команда передаёт название карты из Wallet после ` | `. Приложение ищет его среди названий ваших карт, их названий в Wallet (задаются в настройках карты), последних 4 цифр и банка. Если карта не определилась, операция помечается «карта?». После того как вы выберете карту, приложение запомнит её название в Wallet.
- **Способ 2, незаметно.** Команда дописывает строку `AKSHA;<дата ISO 8601>;<сумма>;<продавец>;<карта>` в файл `Aksha.txt` в iCloud Drive. Файл загружается через «+» → «Выписка», повторы отсекаются.

Оба способа видят только оплаты Apple Pay. Переводы и оплаты внутри банковских приложений добавляются выпиской.

## Как защищены данные

- **Шифрование.** Все операции шифруются на устройстве: AES-256-GCM, ключ получается из пароля через PBKDF2-SHA256 (310 000 итераций). Пароль и ключ никуда не отправляются.
- **Восстановление.** При регистрации выдаётся ключ восстановления. Без пароля или этого ключа данные не открыть никому, включая администратора.
- **Что видно в открытом виде:** только служебный журнал (тип события и время).
- **Блокировка:** автоматическая после бездействия, пауза после 5 неверных попыток входа.

## Где хранятся данные

- **На GitHub Pages и при открытии файла напрямую:** в браузере (`localStorage`), в зашифрованном виде. Данные не переносятся между устройствами.
- **Внутри Claude:** в облачном хранилище артефакта, тоже только шифр.

## Ограничения демо

- Банки напрямую не подключаются. Операции попадают в приложение из пушей, выписок или вручную.
- Разбор PDF-выписки проверен на тестовом файле, а не на реальной выписке банка.
- Значки банков — условные обозначения (инициалы на цветной плашке), а не логотипы банков.
- Казахский перевод нужно проверить носителю языка.

## Свой сервер

Приложение может хранить данные на вашем сервере. Тогда один аккаунт открывается с любого устройства, а покупки Apple Pay уходят на сервер в фоне.

На сервере лежат только зашифрованные данные. Пароль и ключи остаются на устройстве: сервер получает производный ключ входа, который не расшифровывает данные. Исключение — текст покупки Apple Pay: он приходит по HTTPS открытым, сервер сразу шифрует его вашим публичным ключом и не пишет открытый текст ни в базу, ни в логи.

Нужны Ubuntu 24.04, домен с A-записью на IP сервера и открытые порты 80 и 443.

```
apt update && apt install -y git
git clone https://github.com/daulet-tuzelbek/aksha-tracker.git /opt/aksha
sudo bash /opt/aksha/server/install.sh ваш-домен.kz
```

Обновление: `sudo bash /opt/aksha/server/update.sh`. Резервная копия базы: `sudo bash /opt/aksha/server/backup.sh`.

Состав: `server/app.js` (Node 24, без зависимостей, SQLite), `server/Caddyfile` (HTTPS-сертификат автоматически), `server/docker-compose.yml`.
